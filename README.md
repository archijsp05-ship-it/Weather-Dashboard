# 🌦️ Weather Dashboard

A real-time Weather Dashboard built using **HTML, CSS, and JavaScript** that fetches and displays live weather information using a public REST API.

This project demonstrates asynchronous JavaScript concepts, API integration, JSON data processing, and dynamic DOM manipulation.

## ✨ Features

- 🌍 **Real-Time Weather Data:** Fetch current weather information for different cities.
- 🔍 **City Search:** Search for weather conditions by city name.
- 🌡️ **Temperature:** Display current temperature.
- 💧 **Humidity:** Show humidity levels.
- 💨 **Wind Speed:** Display current wind speed.
- ⚡ **Asynchronous API Calls:** Uses Fetch API with async/await.
- ⚠️ **Error Handling:** Handles invalid city names and failed network requests.
- 📊 **Dynamic Data Rendering:** Processes JSON responses and updates the dashboard dynamically.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/archijsp05-ship-it/Weather-Dashboard.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter a city name in the search box to view its current weather information.

## 🔑 API Integration

This project uses a public Weather REST API to retrieve real-time weather information.

The Fetch API is used to send HTTP requests, while async/await handles asynchronous operations. The returned JSON data is processed and displayed dynamically.

**Note:** Configure your own API key if the selected weather API requires authentication.
